# Ғазна · Законы

Учебный справочник по законодательству для нового сотрудника Комитета казначейской службы при МЭФ Узбекистана.
Мобильное PWA: официальные тексты с lex.uz на русском и узбекском (кириллица), оглавление, поиск, закладки, заметки, прогресс, тесты, офлайн.

> В корне репозитория также лежит старый сайт (`index.html`) — сборка приложения его не использует.

## Команды (Windows / macOS / Linux, нужен Node 20+)

| Команда | Что делает |
|---|---|
| `npm install` | установить зависимости |
| `npm run dev` | локальный запуск на http://localhost:3000 |
| `npm run build` | собрать сайт в `out/` (данные + Next.js + Service Worker) |
| `npm run start` | открыть собранный `out/` локально |
| `npm run update-sources` | перекачать акты с lex.uz, показать изменения редакций, пересобрать `content/` |
| `npm run fetch-sources` | скачать недостающие тексты в `sources/` (`-- --import` — взять сохранённые вручную HTML) |
| `npm run parse` | разобрать `sources/` → `content/{акт}/{ru,uz}.json`, отчёт — `content/PARSE_REPORT.md` |
| `npm run data` | пересобрать глоссарий и `public/data/` |
| `npm run acts-table` | пересобрать таблицу актов `ACTS.md` |

## Деплой на Vercel

1. vercel.com → Add New → Project → импортировать этот репозиторий (ветку с приложением).
2. Настройки берутся из `vercel.json` (сборка `npm run build`, папка `out`). Нажать Deploy.
3. На телефоне открыть адрес сайта → «Поделиться» → «На экран Домой» (iPhone) или «Установить приложение» (Android).

## Где что лежит

- `content/acts.json` — реестр актов (номера lex.uz, объём «ядро/доп.»), `ACTS.md` — та же таблица для чтения.
- `sources/` — скачанные страницы lex.uz и gov.uz (сжатые) + `meta.json` с редакцией и контрольной суммой.
- `content/{акт}/{ru,uz}.json` — официальный текст по структуре источника; сюда же на Этапе 5 добавляются `study.{ru,uz}.json` (комментарии) и `tests.{ru,uz}.json` (вопросы).
- `app/`, `components/`, `lib/` — приложение (Next.js App Router, TypeScript, Tailwind).
- `PROGRESS.md` — ход работ по этапам.
